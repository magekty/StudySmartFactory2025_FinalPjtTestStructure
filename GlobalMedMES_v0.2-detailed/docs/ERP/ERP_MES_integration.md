### ERP/MES 연동을 위한 아웃박스 패턴 구현 제안 보고서
1. 개요 및 배경
본 보고서는 ERP와 MES 간의 핵심 데이터(생산계획, 작업지시, BOM 등) 연동을 위한 높은 신뢰성의 비동기 통신 시스템 구축 방안을 제안합니다. 전통적인 동기식 API 호출 방식은 한 시스템의 장애가 전체 연동에 영향을 미치고 데이터 유실 위험이 있어, 이를 해결하기 위해 **아웃박스 패턴(Outbox Pattern)**을 도입하는 것을 목표로 합니다.

## 2. 핵심 구현 방안: 최적의 조합 선택
아웃박스 패턴 구현을 위한 3가지 필수 구성 요소에 대해, 프로젝트의 요구사항을 고려하여 아래와 같이 가장 이상적인 조합을 선택했습니다.

# 2.1. 아웃박스 패턴 로직 형식
선택: 비즈니스 데이터 저장과 outbox 테이블 기록을 단일 데이터베이스 트랜잭션으로 처리하는 로직을 구현합니다.

## 핵심 원칙:

- 데이터 유실 방지: 비즈니스 데이터(예: 생산 계획)가 ERP DB에 성공적으로 저장되는 동시에, 발행할 메시지가 outbox 테이블에 함께 기록되도록 보장합니다. 이 두 작업 중 하나라도 실패하면 전체 트랜잭션이 롤백됩니다.

- 강력한 재시도: 메시지 브로커로의 발행 단계에서 실패가 발생하더라도, DB 상태에는 영향을 주지 않고 메시지 발행에 성공할 때까지 무한정 재시도합니다.

- 선택 근거: 이 방식은 DB의 원자성을 활용하여 메시지 유실의 원인을 근본적으로 차단합니다. 이는 중요한 생산 데이터를 다루는 ERP/MES 환경에 필수적인 요소입니다.

# 2.2. 데이터 변경 감지자 (Observer)
- 선택: CDC(Change Data Capture) 기술을 활용합니다.

- 선택 이유:

- 높은 실시간성: DB의 트랜잭션 로그를 직접 모니터링하여 거의 실시간으로 변경을 감지합니다. 생산 현황과 같이 빠른 피드백이 필요한 데이터에 적합합니다.

- 낮은 DB 부하: outbox 테이블을 반복적으로 조회하는 폴링(Polling) 방식과 달리, DB 성능에 영향을 주지 않아 핵심 업무 처리를 방해하지 않습니다.

- 대안과의 비교:

- 폴링: 구현이 쉽지만, 일정 주기마다 DB를 조회하므로 지연이 발생하고 불필요한 부하를 유발합니다. 중요한 비즈니스 데이터의 신속한 연동이 필요한 본 프로젝트에는 부적합합니다.

# 2.3. 메시지 브로커
-선택: RabbitMQ를 사용합니다.

- 선택 이유:

- 안정성과 신뢰성: 메시지를 디스크에 저장하고, 발행-구독 시스템에서 메시지 유실을 방지하는 강력한 기능을 제공합니다.

- 적정 성능: Kafka와 같은 초대용량 브로커에 비해 구조가 단순하고 운영이 용이합니다. 본 프로젝트의 데이터 양은 초대용량 스트리밍에 해당하지 않으므로, RabbitMQ의 성능만으로도 충분합니다.

- 비용 효율성: 불필요한 복잡성과 높은 자원 소모를 피하여, 개발 및 운영 비용을 절감할 수 있습니다.

- 대안과의 비교:

- Kafka: 대용량 데이터 스트리밍에 최적화되어 있어, 본 프로젝트의 규모에서는 오버스펙입니다. 불필요한 복잡성과 높은 운영 비용을 감수할 필요가 없습니다. RabbitMQ의 순서 보장 로직을 구현하는 것이 Kafka의 오버스펙을 감당하는 것보다 훨씬 합리적입니다.

## 3. 리스크 분석 및 대응 방안
- 리스크: 메시지 재전송으로 인한 중복 메시지 문제.

- 대응: 모든 메시지에 고유 ID를 부여하고, 수신 측(MES/ERP)에서 멱등성(Idempotency) 로직을 구현하여 이미 처리된 메시지는 무시하도록 처리합니다.

- 리스크: 메시지 브로커와 관련된 운영 복잡성.

- 대응: 메시지 발행 및 소비 실패 시 **데드 레터 큐(Dead Letter Queue)**를 활용하여 오류 메시지를 별도로 관리하고, 시스템의 주요 지표를 모니터링하여 문제 발생 시 즉시 대응할 수 있는 시스템을 구축합니다.

## 4. 최종 결론
본 보고서가 제안하는 CDC + RabbitMQ 조합은 ERP/MES 연동 환경의 특성을 가장 잘 반영한 최적의 솔루션입니다. 높은 신뢰성과 적절한 성능, 그리고 효율적인 운영을 모두 만족시킬 수 있으며, 핵심 비즈니스 데이터의 유실을 방지하여 시스템의 안정성을 극대화할 것입니다.
